# twibbonsawit 

Jadi ini kayak dupenya twibbonize for free penggunaannya. Pengguna memilih foto, menggeser dan meng-zoom foto di balik bingkai twibbon, lalu mengunduh hasilnya sebagai PNG.

## Fitur
- Unggah foto lewat tombol atau seret & lepas
- Geser foto dengan mouse/jari, zoom dengan cubit (pinch), scroll, slider, atau tombol +/−
- Putar foto
- Dua twibbon bawaan, ditambah unggah twibbon sendiri (PNG transparan)
- Unduh hasil dalam resolusi penuh twibbon (1080×1080 untuk bingkai bawaan)
- Semua diproses di browser, foto tidak dikirim ke server
